# App Architecture

nav-gauge is a cross-platform toolkit composed of pluggable Gears. The web and mobile apps assemble these features on top of shared application logic, UI, and utilities.

## Platform boundaries

- **Common** packages contain platform-neutral behavior and APIs.
- **Web** packages may import matching web and common packages from lower layers, plus their own common package.
- **Mobile** packages follow the same rule for mobile and common packages.
- Common packages never import platform implementations. Web and mobile packages never import one another.
- Platform UI renderers are consumed by matching Gears and Apps; Apparatus may use UI Common.
