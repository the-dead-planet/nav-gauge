- `panelProps` selects the surface appearance and interaction. Persistent tiles default to raised elevation.
- `size` controls body padding and action sizing. Body padding excludes the footer.
- `actions(size, variants)` receives the shared primary/active and secondary/inactive button variants. Follow the <a href="./?path=/docs/design-system-appearance--docs#actions-on-surfaces" target="_top" style={{ textDecoration: 'underline' }}>action variant policy</a> and <a href="./?path=/docs/design-system-appearance--docs#action-footers" target="_top" style={{ textDecoration: 'underline' }}>footer alignment and spacing</a> shared with Dialog.
