Radios default to circular corners. The `corners` prop also accepts `square` and `hexagon`; the selected inner marker follows the same shape as the outer indicator.

All shapes reserve the same icon-sized indicator slot so changing shape or checked state preserves row alignment.

See <a href="./?path=/docs/design-system-appearance--docs#corners-and-shapes" target="_top" style={{ textDecoration: 'underline' }}>Appearance</a> for shared shape geometry and visual intent.
