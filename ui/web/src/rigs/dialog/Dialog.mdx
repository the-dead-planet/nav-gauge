- Uses shared <a href="./?path=/docs/design-system-appearance--docs" target="_top" style={{ textDecoration: 'underline' }}>appearance rules</a> in the inherited theme; `themeMode` overrides the whole dialog. The translucent title opts into text shadow.
- `backdrop` defaults to `true`: neutral `100` in light mode or `900` in dark mode, at 60% opacity. This supports readable translucent surfaces. Set it to `false` for an untinted modal overlay.
- Save is primary; Close is secondary. See <a href="./?path=/docs/design-system-appearance--docs#actions-on-surfaces" target="_top" style={{ textDecoration: 'underline' }}>action variants</a>.
- Content-sized, capped to the viewport and mobile safe areas. Only the body scrolls; the header and actions stay visible.
