## Tab appearance

Selected and inactive tab variants follow the shared <a href="./?path=/docs/design-system-appearance--docs#actions-on-surfaces" target="_top">actions-on-surfaces table</a>.

Selection changes the button variant without forcing its pressed appearance. Hover, focus, press, explicit highlighting, and disabled treatment follow the shared appearance policies. The same variant mapping applies to the overflow trigger and measurement buttons.
