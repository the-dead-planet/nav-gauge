## Appearance and interaction

`variant` styles the trigger; the popup uses `fill-inverse`. Rows use the shared `menu-item` policy.

Highlight palette: rows use `highlightColor ?? color`; the trigger uses `iconActiveColor ?? highlightColor ?? color`.

`selected` reuses the active/pressed appearance. See <a href="./?path=/docs/design-system-appearance--docs#appearance-states" target="_top">shared state priority</a>.

Selected items use radio semantics on both platforms.

## Navigation indicators

Web links infer an internal arrow for same-origin navigation, or an external arrow for other origins / `target="_blank"`. Set `linkType` for callback-based navigation, including mobile. Dialog actions have no indicator.

Indicators are decorative, inherit the row's glyph color, and reserve space before loading.

## Sizing

`size` controls trigger and row geometry, font size, and icons. Rows inherit it unless overridden.

The popup fits its widest row, capped by the viewport; long labels wrap when needed.

List padding is vertical only: `xs` at sizes `xs` / `sm`, and `sm` at sizes `md` / `lg`. Rows own label padding. See <a href="./?path=/docs/design-system-sizing--docs" target="_top">Sizing</a>.
