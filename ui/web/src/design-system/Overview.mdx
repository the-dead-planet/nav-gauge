# Design System

This design system guides The Dead Planet's cross-platform interfaces.

## Principles

- **Industrial voice, clear meaning.** Use a dystopian, steampunk, cyber-inspired voice with a cheeky, playful edge—without obscuring meaning.
- **Instrument and ornament.** Use mechanical detail for atmosphere without misleading about structure or state.
- **Simple first, depth on demand.** Make common goals achievable in a few steps, with a clear path to advanced control.
- **One toolkit, platform-fit workflows.** Preserve transferable work while adapting interactions and available controls to each device.

Reveal deeper controls within the same workflow so refinement does not require starting over.

**Platform fit.** Mobile often favors quick creation and sharing; desktop often favors longer editing sessions. These are contexts, not expertise levels. Feature availability can differ by device.

**Gears.** Gears are independent tools that may optionally participate in one workflow. Each gear documents its goal, quick path, and advanced path. Reuse personas where audiences overlap; add one only for distinct needs or working conditions.
