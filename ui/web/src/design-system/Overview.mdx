This design system defines the shared visual and interaction rules for Nav Gauge web and mobile interfaces: color, typography, sizing, spacing, geometry, component states, motion, and accessibility.

The visual and verbal identity is dystopian, steampunk, and cyber-inspired. It shapes geometry, typography, color, motion, component names, labels, tooltips, and system messages.

## Principles

- **Instrument, not ornament.** Bevels, notches, connectors, glow, and mechanical details should communicate structure or state rather than decorate empty space.
- **Atmosphere in voice, clarity in meaning.** User-facing text may use terse industrial or system-oriented language, but actions, errors, tooltips, and accessibility labels must remain immediately understandable.
- **State does not rely on one cue.** Active, disabled, selected, and focused states must remain distinguishable without relying only on color or motion.
- **Content controls layout.** Surfaces frame their content without imposing spacing that prevents full-width rows or specialized compositions.
