# Appearance

Appearance coordinates a component's surface, border, glyph color, font weight, and interaction effects. Shared policies in `ui/common/src/design-system/theme/` supply the same treatment on web and mobile. Palette construction and contrast calculations are defined in <a href="./?path=/docs/design-system-colors--docs" target="_top" style={{ textDecoration: 'underline' }}>Colors</a>.

<h2 id="appearance-defaults">Defaults</h2>

Components that expose `color` default to `neutral`.

`variant` defaults to `ghost`, or `fill-inverse` when `ghost` is unsupported. Components without an appearance variant use the shared default policy.

<h2 id="interaction-states">Interaction states</h2>

Disabled state always wins. Hover and focus temporarily use their interaction shade, while pressed and persistent active use the stronger active shade. Interactive states use `highlightColor ?? color`; default and disabled states use `color`. Focus also has a visible focus indicator. Interact with the default and active examples to inspect their transient states.

<h2 id="glyphs">Glyphs</h2>

Appearance policies may optionally set `glyphs.fontWeight` per state. Owned text uses that weight unless explicitly overridden; omitting it leaves the component's normal typography weight unchanged. Supported weight values and override precedence are defined in <a href="./?path=/docs/design-system-typography--docs#font-weight" target="_top" style={{ textDecoration: 'underline' }}>Typography</a>.

Owned active content uses `highlightContentShade` when supplied, otherwise the variant's existing contrast rule. Components must not recolor arbitrary children or apply whole-control opacity when they own surface and content channels.

Inset controls use no border in any state. Their internal shading alone creates the appearance of a control dented into its surface.

## Active glow

`activeGlow` is an optional enhancement to the existing color, border, and content state cues. It uses `highlightColor`, never replaces the required state treatment, and is removed when a component is disabled.
