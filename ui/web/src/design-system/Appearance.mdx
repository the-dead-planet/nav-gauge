# Appearance

Appearance coordinates the visual parts of a component:

- **Surface:** background color, transparency, and depth effects.
- **Border:** color and width.
- **Glyphs:** text and icon color, plus optional font weight.
- **Size:** component geometry and content scale.
- **Interaction effects:** visual feedback for hover, focus, pressed, highlighted, and disabled states, including optional glow.

Shared appearance policies supply the same treatment on web and mobile.
Contrast paints derive their background shade from the same state's surface; it is not configured separately.

<h2 id="appearance-states">Appearance states</h2>

The highest-priority applicable state wins. Glyph overrides are optional; otherwise the appearance policy supplies the shade.

<table>
    <thead>
        <tr><th>Priority</th><th>State</th><th>Color</th><th>Glyph override</th><th>Behavior</th></tr>
    </thead>
    <tbody>
        <tr><td>1 (highest)</td><td>Disabled</td><td><code>color</code></td><td>Ignored; uses disabled policy colors</td><td>Overrides all other states. Disabled actions cannot activate and use a <code>not-allowed</code> cursor on web.</td></tr>
        <tr><td>2</td><td>Active / pressed</td><td><code>highlightColor ?? color</code></td><td><code>highlightGlyphsShade</code></td><td>Persistent while <code>highlighted</code>, or temporary during a press. Hover and focus do not replace this appearance.</td></tr>
        <tr><td>3</td><td>Hover / focus</td><td><code>highlightColor ?? color</code></td><td><code>highlightGlyphsShade</code></td><td>Temporary feedback when neither highlighted nor pressed.</td></tr>
        <tr><td>4 (lowest)</td><td>Default</td><td><code>color</code></td><td><code>glyphsShade</code></td><td>Applies when no higher-priority state is active.</td></tr>
    </tbody>
</table>

Focus has a visible indicator even while highlighted; disabled appearance still takes precedence.

Interact with the default and highlighted examples to inspect their transient states.

<h2 id="glyphs">Glyphs</h2>

- <a href="./?path=/docs/design-system-typography--docs" target="_top" style={{ textDecoration: 'underline' }}>Typography</a> defines text hierarchy, font weight, and text-specific overrides.
- <a href="./?path=/docs/design-system-icons--docs" target="_top" style={{ textDecoration: 'underline' }}>Icons</a> defines icon meaning, sizing, and accessibility.

## Active glow

`activeGlow` is an optional enhancement to the existing color, border, and content state cues. It uses `highlightColor`, never replaces the required state treatment, and is removed when a component is disabled.
