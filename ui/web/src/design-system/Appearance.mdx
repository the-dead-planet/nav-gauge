# Appearance

Appearance coordinates the visual parts of a component:

- **Surface:** background color, transparency, and depth effects.
- **Border:** color and width.
- **Glyphs:** text and icon color, plus optional font weight.
- **Size:** component geometry and content scale.
- **Interaction effects:** visual feedback for hover, focus, pressed, highlighted, and disabled states, including optional glow.

Shared appearance policies supply the same treatment on web and mobile.

<h2 id="appearance-states">Appearance states</h2>

Appearance states are listed from highest to lowest priority:

- **Disabled:** overrides all other states and uses `color`.
- **Active / pressed:** uses `highlightColor` and `highlightGlyphsShade` (if supplied), persistently while `highlighted` is enabled or temporarily while the control is being clicked / pressed. Hover and focus do not replace this appearance.
- **Hover / focus:** temporarily uses `highlightColor` and `highlightGlyphsShade` (if supplied) when the control is neither highlighted nor pressed. Focus also has a visible focus indicator, including when highlighted.
- **Default:** uses `color` and `glyphsShade` (if supplied) when no higher-priority state applies.

Interact with the default and highlighted examples to inspect their transient states.

<h2 id="glyphs">Glyphs</h2>

Glyphs are a component's text and icons:

- <a href="./?path=/docs/design-system-typography--docs" target="_top" style={{ textDecoration: 'underline' }}>Typography</a> defines text hierarchy, font weight, and text-specific overrides.
- <a href="./?path=/docs/design-system-icons--docs" target="_top" style={{ textDecoration: 'underline' }}>Icons</a> defines icon meaning, sizing, and accessibility.

Inset controls use no border in any state. Their internal shading alone creates the appearance of a control dented into its surface.

## Active glow

`activeGlow` is an optional enhancement to the existing color, border, and content state cues. It uses `highlightColor`, never replaces the required state treatment, and is removed when a component is disabled.

    <thead>
