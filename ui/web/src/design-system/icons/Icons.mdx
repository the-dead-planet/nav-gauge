# Icons

Icons identify actions, tools, and status. Prefer an existing icon with the correct meaning over a visually similar substitute.

- Icon-only controls require an accessible label.
- Decorative icons must not repeat adjacent text to assistive technology.
- Use the component size scale rather than arbitrary icon dimensions inside controls.
- Do not rely on icon shape alone when an unfamiliar action needs a visible label.

## Rendering and appearance

Icons are glyphs, with no surface variant or container shape. Their color and state follow the <a href="./?path=/docs/design-system-appearance--docs" target="_top" style={{ textDecoration: 'underline' }}>default appearance policy</a>.
