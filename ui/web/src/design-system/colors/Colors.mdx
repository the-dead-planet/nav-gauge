# Colors

Colors use perceptually ordered shades from `50` through `900`. Shade `500` defines each palette's identity; the surrounding shades preserve its hue while moving toward light and dark endpoints. Neutral palettes additionally limit chroma so they remain suitable for surfaces and text.

## Shade roles

Surface, border, and glyph shades follow the <a href="./?path=/docs/design-system-appearance--docs#variants" target="_top" style={{ textDecoration: 'underline' }}>Appearance variant tables</a>. Shade `50` is reserved for optional bright details; verify contrast for the actual color pairing and text size.

<h2 id="contrast-shades">Contrast shades</h2>

A contrast shade uses the background's palette: `100` on dark shades or `900` on light shades, selected by the shared OKLCH lightness threshold. Recalculate it whenever the background shade changes.

## Palettes

Components that expose `color` default to `neutral` when no color is specified.

Use the copy button at the end of a row to copy that palette as RGB JSON.
