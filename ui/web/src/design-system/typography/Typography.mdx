# Typography

Typography carries both hierarchy and product voice. Font choice must follow the role of the text rather than personal preference.

Use the default font unless the content clearly matches another role. Special messaging and neon fonts lose their effect when used frequently and reduce readability in long text.

Use tabular numerals for changing values when stable character widths prevent the surrounding layout from shifting.

Typography's `variant` controls text hierarchy; its glyphs follow the <a href="./?path=/docs/design-system-theming--docs#appearance-defaults" target="_top" style={{ textDecoration: 'underline' }}>default appearance policy</a>. `shade` overrides default content; `highlightShade` resolves against `highlightColor ?? color`. Links own their native hover, keyboard focus, and pressed states, following the <a href="./?path=/docs/design-system-colors--docs" target="_top" style={{ textDecoration: 'underline' }}>shared color and interaction rules</a>.
