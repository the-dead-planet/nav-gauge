Use the default font unless the content clearly matches another role. Special messaging and neon fonts lose their effect when used frequently and reduce readability in long text.

Use tabular numerals for changing values when stable character widths prevent the surrounding layout from shifting.

## Text sizing

The `usage` hierarchy uses these shared defaults on web and mobile. Values are CSS pixels on web and logical units on mobile. Use `<Caption>` for short supporting text; it renders the `caption` hierarchy without specifying `usage` manually (a `<span>` on web, native text on mobile).

Control labels follow the <a href="./?path=/docs/design-system-sizing--docs" target="_top" style={{ textDecoration: 'underline' }}>control size scale</a> rather than the text hierarchy. Player and <a href="./?path=/docs/gizmos-button--docs" target="_top" style={{ textDecoration: 'underline' }}>button captions</a> share the `caption` typography above; only button captions are uppercase.

<h2 id="font-weight">Font weight</h2>

`fontWeight` accepts numbers `100` through `900` in steps of `100`, their string equivalents (such as `"300"` and `"800"`), and `"normal"` / `"bold"`. The keywords resolve to `400` and `700` respectively on both platforms.

Appearance policies may supply a font weight per state. An explicit `fontWeight` takes precedence over the existing `bold` shorthand, then the appearance policy's optional glyph weight, then the text hierarchy's default.

Available weights vary by font. Web may synthesize weights; mobile selects the nearest supported face within the chosen family, clamping requests outside its range to the thinnest or boldest bundled face.

`usage` selects `header`, `body`, or `caption` hierarchy. Optional `variant` selects the <a href="./?path=/docs/design-system-appearance--docs" target="_top" style={{ textDecoration: 'underline' }}>appearance policy</a>'s glyph color and weight without painting a background or border; omitting it preserves the default/inherited treatment. `shade` and `highlightShade` override glyph shades. Links follow the <a href="./?path=/docs/design-system-appearance--docs#appearance-states" target="_top" style={{ textDecoration: 'underline' }}>shared interaction states</a>.
